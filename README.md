## 📌 Project Overview
 
This project is a **multi-page interactive Power BI dashboard** built for comprehensive financial analysis. It covers 6 key analytical areas — from high-level financial overview to granular transaction risk analysis — enabling stakeholders to make informed, data-driven financial decisions.
 
---
 
## 🎯 Dashboard Pages & Features
 
### 📊 1. Financial Overview
- High-level KPIs — Total Revenue, Net Profit, Expenses, Profit Margin
- Period-wise financial performance trends
- Revenue vs Expense comparison charts
### 🛒 2. Sales Performance
- Sales trend analysis across time periods
- Top-performing products/categories by revenue
- MoM & YoY sales growth tracking
### 👥 3. Customer Insights
- Customer segmentation by type and behavior
- High-value customer identification
- Customer-wise revenue contribution analysis
### 💳 4. Payment Analysis
- Payment mode distribution (Card, COD, Online, etc.)
- Payment status tracking (Paid vs Unpaid)
- Average transaction value by payment method
### ⚠️ 5. Transaction Risk Analysis
- High-risk transaction identification
- Anomaly detection in payment patterns
- Risk categorization for financial decision-making
### 🔍 6. Tooltip — Payment Method Split
- Interactive tooltip showing payment method breakdown
- Drill-through capability for detailed payment insights
- Dynamic split visualization on hover
